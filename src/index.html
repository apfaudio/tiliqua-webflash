Setup

  • macOS: No setup needed.
  • Windows: Use Zadig to install a WinUSB driver for the device:
    1. Plug in Tiliqua
    2. Run Zadig
    3. In the menu, under 'Options', choose 'List All Devices'
    4. In the main drop down, select the Tiliqua 'apfbug' device
    5. Select 'WinUSB' in the drop down near the green arrow
    6. Click 'Install Driver', wait for it to complete.
    7. Refresh this page, flashing should work.
  • Linux: You may need to add a udev rule so Tiliqua can be accessed without sudo.

Connecting

  1. Wait for 'Ready' to be shown: it takes a few seconds for the dependencies to be downloaded.
  2. Connect Tiliqua: Connect 'dbg' (top) USB port to your computer. Click 'Connect to Tiliqua' button, select your device.
